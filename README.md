# Datacom Software Development — Job Simulation (Forage)

This repository documents my completion of the **Datacom Software Development Job Simulation** on [Forage](https://www.theforage.com/simulations/datacom/software-development-l47g), a self-paced virtual work-experience programme designed by Datacom's software development team.

It's a practical, self-guided exercise designed to mirror the kind of review-and-fix work a Datacom developer does day to day. ## What the Simulation Covered

The programme consisted of two practical tasks, working as a developer on an existing client web application:

1. **Software Review** — Reviewed the application's functionality, user experience, and code structure, then planned and documented a prioritised set of improvements.
2. **Identifying Root Causes & Fixing Bugs** — Reproduced reported defects, traced each one back to its actual root cause using the codebase and browser developer tools, implemented fixes, and verified the corrected behaviour.

## Skills Practiced

- Reading and navigating an unfamiliar codebase
- Structured software review and prioritisation of findings
- Systematic, hypothesis-driven debugging (reproduce → isolate → diagnose → fix)
- Root-cause analysis vs. surface-level patching
- Browser developer tools and step-through debugging
- Technical documentation and communication
